**ZahiCraft** — Remastered is a browser-based, block-building 3D game inspired by sandbox classics made by HTML, some CSS and Three.JS, It lets players explore and interact with a simple world where you can move, jump, place, and remove blocks to build your own environments — all in the browser with no installation required. 
zahicraft.onrender.com

**🚀 Features**

**Movement Controls:**

W, A, S, D — Move

SPACE — Jump

**Build & Modify:**

Left-click to place blocks

Right-click to remove blocks

Block Selection:

Press 1 to 8 to switch between block types (e.g., Grass, Dirt, Stone)

**Web-first Experience:** Play instantly in your browser — no downloads or setup needed. 
https://zahicraft-multiplayer.onrender.com/

ZahiCraft Multiplayer is a browser-based, block-building Multiplayer 3D game inspired by sandbox classics.
